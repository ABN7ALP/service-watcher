# البند 4-5 — موثوقية إنهاء البث التلقائي: إثبات بخادم حي فعلي

نفس منهجية `docs/verification/pr102-item5/` (انقطاع/قتل/إعادة تشغيل حقيقي فعلياً، لا محاكاة).

## السيناريو

1. مضيف يدخل بثّه المباشر فعلياً (`server/server.js` حقيقي + `mongodb-memory-server`
   replica set حقيقي + Playwright/Chromium حقيقي).
2. متفرّج حقيقي آخر يدخل نفس الغرفة.
3. **انقطاع حقيقي**: إغلاق سياق متصفح المضيف بالكامل (socket.io بالخادم يتلقّى `disconnect`
   حقيقياً — لا استدعاء دالة داخلية).
4. بعد 40 ثانية: **قتل عملية الخادم (`SIGKILL`)** — محاكاة تعطّل/إعادة نشر حقيقية.
5. بعد ~12 ثانية توقّف كامل: **إعادة تشغيل الخادم** — عملية Node جديدة بالكامل، بلا أي
   مؤقّت ذاكرة من العملية السابقة، متصلة بنفس قاعدة البيانات الحيّة.
6. انتظار حتى اكتمال نافذة الـ120 ثانية (`HOST_DISCONNECT_END_MS`) من لحظة الانقطاع
   الفعلية، مع فحوصات دورية مباشرة على قاعدة البيانات.

## ملاحظة بصراحة: تأكيد وصول `room-broadcast-ended` لصفحة المتفرّج

حاولنا أيضاً إثبات وصول الحدث الحي لمتصفح المتفرّج (`#broadcast-ended-screen` يظهر) بعد
إعادة اتصاله التلقائي بالخادم الجديد. **لم يظهر خلال نافذة انتظار 20 ثانية بعد تأكيد الإنهاء
بقاعدة البيانات.** فحص سجلّ الخادم الثاني يُظهر أن سوكيت المتفرّج اتصل مرة واحدة بعد إعادة
التشغيل ثم انقطع ولم يُعِد الاتصال مجدداً طوال باقي الاختبار (~100 ثانية) — رغم أن
`socket.io-client` الحقيقي يعيد الاتصال تلقائياً بإعدادته الافتراضية دون أي تدخّل. هذا
النمط (اتصال واحد قصير ثم صمت تام، لا محاولات إعادة اتصال متكرّرة) يتوافق أكثر مع **تقييد
Chromium لمؤقّتات تبويب/سياق متصفح غير نشط (background throttling)** بهذي البيئة تحديداً
(عدة سياقات Playwright مفتوحة بنفس الجلسة، لا تركيز مستمر على صفحة المتفرّج) — لا مع عطل
بمنطق `rejoinRoomChatChannel`/`join-room-chat` نفسه (مُتحقَّق منه سكونياً: يعمل عند أي
`connect`، ويضمّ السوكيت فعلياً لقناة `room-chat-<roomId>` بالخادم — راجع الكود). **هذا
استنتاج مرجَّح لا إثبات قطعي** — يُذكر هنا بصراحة كنتيجة غير حاسمة، لا كادّعاء نجاح كامل غير
دقيق. آلية النبضة الصريحة المُضافة بهذا الـPR (`client-heartbeat` عند `visibilitychange`،
البند 5) مصمَّمة أصلاً لتغطية جزءاً من فئة المشاكل هذي للمضيف تحديداً (لا للمتفرّجين).
