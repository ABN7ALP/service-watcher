## قيود بيئة الاختبار الحالية (موثَّقة بصراحة، غير مؤثّرة على صحة النتائج)

- **`res.cloudinary.com` محجوب**: صور المستخدمين الافتراضية/أصول الإطارات الحقيقية تظهر
  كصورة مكسورة باللقطات — تجميلي بحت، أصول الإطارات المحلية (`/assets/frames/*.webp`)
  سليمة ومُحمَّلة بنجاح دوماً (مُتحقَّق منه مباشرة — `200`، أبعاد صحيحة).
- **`cdn.socket.io` محجوب**: اعتُرِض الطلب بأداة الاختبار فقط (Playwright route interception)
  وأُرجِعت نسخة `socket.io-client` الحقيقية المحلية (`node_modules/socket.io/client-dist`)
  محلّه — لا تعديل على أي ملف إنتاجي، `index.html` يحمّل من CDN فعلاً بالإنتاج كما هو.
- **بيئة اختبار مشتركة الموارد**: عملية `mongod` + منسّق Node الخارجي + اتصالات `socket.io`
  المحاكية للمرسلين تعمل جميعها على نفس الجهاز المشترك فعلياً أثناء اختبار سيل الهدايا —
  بخلاف الإنتاج (مرسلون على أجهزة/شبكات منفصلة تماماً عن جهاز المضيف) — موثَّق بتفصيل أكبر
  بملخّص سيل الهدايا متعدد التشغيلات.
