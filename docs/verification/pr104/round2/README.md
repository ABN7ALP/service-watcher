# PR #104 — الجولة 5: إصلاح انحدار هندسي من الكوميت `1aefccf` (شارات/تاج تطفو خارج خلية المقعد)

ملاحظة مُلزمة من طلب المراجعة: **لم يُلمَس batching الهدايا، ولا مسح قطع اتصال المضيف، ولا
الإصلاح الأمني (بما فيه محدد المعدل العام)، ولا تغييرات `io.to`، ولا منطق توليد
الإطارات/سرعة الحركة — كل هذا مُعتمَد مسبقاً ولم يتغيّر بهذه الجولة بتاتاً. التغيير الإنتاجي
الوحيد هذي الجولة: `public/src/input.css` (+ `public/dist/style.css` المبني منه) و
`public/js/app.js`، بالضبط كما يفصّل هذا الملف.**

## 1) الانحدار المُبلَّغ

كوميت `1aefccf` (إصلاح الجولة 4) أرسى شارة رقم المقعد/المايك وتاج المضيف جميعاً بالنسبة
لحافة **صندوق الإطار الزخرفي** (`--frame-box`، 140–170% حسب كثافة الشبكة) بدل حجم دائرة
الصورة الفعلي (`--av`/`--hostAv`). بما أن صندوق الإطار أوسع من خلية المقعد نفسها بالشبكات
الضيقة، طفت هذي الزخارف الثلاث فعلياً خارج حدود خليتها بالكامل:

- شارات المايك غطّت اسم المقعد المجاور (`lack-gold-crown`، `on-bee-sapphire` مقصوصان
  باللقطة المرفقة بطلب المراجعة).
- أرقام مقاعد الصف الأول (5، 4، 3، 2) جلست فوق سطر اسم/رصيد المضيف.
- مايك ورقم مقعد المضيف نفسه ابتعدا عنه بصرياً.
- تاج المضيف طفا ~30px فوق الصورة واصطدم أحياناً بشريط إعلان الغرفة (غرفتا 9 و19).

## 2) القاعدة الهندسية الجديدة المطبَّقة

### أ) شارة الرقم + المايك: الاحتواء داخل خلية المقعد، لا `--frame-box`

الإرساء عاد لحجم `.voice-seat-av-wrap` الصغير (`var(--av)`/`var(--hostAv)` — حجم دائرة
الصورة نفسها، لا صندوق الإطار الأوسع)، بإزاحة داخلية 1px فقط (كانت `-1px`، أي خارج الحافة
فعلياً — خطأ إشارة بسيط صحَّحته المراجعة الآلية أدناه: 21 انتهاك "outside-cell" للرقم قبل
الإصلاح). التراكب مع زخرفة الإطار نفسها مقبول صراحة بطلب المراجعة؛ غير المقبول فقط هو تجاوز
حدود الخلية أو تغطية أي نص. بما أن `.voice-seat-av-wrap` يقع دوماً بمنتصف خليته
(`align-items:center`) بهامش كافٍ قبل سطر الاسم، هذا الإرساء يضمن الاحتواء داخل الخلية
تلقائياً بلا أي حساب إضافي خاص بالكثافة.

### ب) تاج المضيف: صيغة موحَّدة بمرجع سياقي (`--crown-ref-h`)

بدل الاعتماد دوماً على `--frame-box` (حتى بلا إطار إطلاقاً، وهو أصل الانحدار الثاني — طفو
~30px)، أُضيف متغيّر مرجعي واحد يحمل القيمة الصحيحة حسب السياق تلقائياً عبر `:has()`:

```css
.voice-seat-av-wrap { --crown-ref-h: 100%; }
.voice-seat-av-wrap:has(.avatar__frame) { --crown-ref-h: var(--frame-box, 170%); }
```

فتُصبح صيغة واحدة تخدم الحالتين (بإطار/بلا إطار) بلا تفرّع CSS مكرَّر:

```css
top: calc((100% - var(--crown-ref-h)) / 2 + var(--crown-ref-h) * (0.175 - var(--crown-extra-lift, 0)));
transform: translate(-50%, -100%) rotate(-8deg);
```

`(100% - crownRefH)/2` = حافة الحلقة/الصندوق العلوية (صفر بلا إطار، سالبة مع إطار).
`+ 17.5% من crownRefH` = منتصف نطاق التراكب المطلوب (15–20% من أعلى الحلقة/الصندوق).
`translateY(-100%)` يرفع التاج كاملاً فوق هذي النقطة، فتصبح حافته السفلية بالضبط هناك —
متصل دوماً بالحلقة/الصندوق، لا يطفو أبداً، بصرف النظر عن وجود إطار أو كثافته.

### ج) استثناء موثَّق: `--crown-extra-lift` للإطارين ذوي الزخرفة العلوية الكثيفة

إطارا **الأدمن** و**التاج الأسود والذهبي** لهما زخرفة بارزة (أسدان متقابلان / تاج+أسود) قرب
قمة الصندوق نفسها — عند نفس نقطة الالتصاق القياسية، تجلس شارة التاج فوق "تاج" الإطار نفسه
بصرياً. استثناء صغير موثَّق صراحة (لا قاعدة عامة) يرفع نقطة الالتصاق 8% إضافية لهذين الإطارين
فقط، عبر `--crown-extra-lift` المضبوطة من JS (`HOST_CROWN_EXTRA_LIFT` بـ`app.js`، قيمتها 0
افتراضياً لبقية الإطارات الـ9 — بلا أي أثر عليها).

### د) مسافة دفاعية بين صفّ المضيف والصفّ الأول

`.voice-seat.host-seat`: `margin-bottom` من `0.3u` إلى `1.1u` (دفاعي، فوق إصلاح تموضع
الشارات نفسه)، و`padding-top: calc(var(--hostAv, var(--av)) * .6)` يحجز مساحة فعلية ضمن
صندوق خلية المضيف نفسها لارتفاع التاج (أسوأ حالة محسوبة: ~0.53×hostAv فوق حافة الحلقة بسياق
`--frame-box=170%` + رفع إضافي) — يمنع التاج من الخروج من خلية `.voice-seat.host-seat` نفسها
وملامسة شريط إعلان الغرفة فوق الشبكة.

## 3) الفحص الآلي (الهندسي) — المطلوب صراحةً

هارنس Playwright حقيقي (خادم Express/Socket.IO حقيقي + `mongodb-memory-server`، لا تقديرات
CSS) يبذر **12 غرفة/مضيفاً مستقلّين تماماً** (حجم مقاعد × عرض شاشة، كل تركيبة لم تُزَر إلا
مرة واحدة فعلياً — يطابق سلوك منتج حقيقي):

| الحجم | إطار المضيف | العروض المفحوصة |
|---|---|---|
| 9 مقاعد | بلا إطار | 320 / 375 / 430px |
| 13 مقعداً | التاج الأسود والذهبي | 320 / 375 / 430px |
| 19 مقعداً | الأدمن | 320 / 375 / 430px |
| 80 مقعداً | الأسد والنحلة والياقوت | 320 / 375 / 430px |

كل غرفة بإشغال كامل، أسماء طويلة عربية/إنكليزية ثنائية اللغة، 19 صورة اختبار محلية حقيقية
دوّارة، وكل الإطارات الـ11 دوّارة على مقاعد غير المضيف.

لكل مقعد بكل حالة، يقيس `getBoundingClientRect()` فعلياً (لا تقديراً):

1. **الاحتواء**: صندوق شارة الرقم/المايك/التاج يقع بالكامل داخل صندوق خلية مقعده هو بالذات.
2. **عدم التقاطع**: لا صندوق زخرفي يتقاطع مع صندوق اسم/رصيد **أي** مقعد (لا مقعده فقط)، ولا
   مع شريط إعلان الغرفة.
